# Age Calculator

This is a simple Age Calculator application built using HTML, CSS, and JavaScript. The application allows users to input their birthdate using a datepicker and calculates their exact age in years, months, and days using the Luxon library.

## Features

- User-friendly datepicker for inputting birthdate
- Calculates exact age in years, months, and days
- Basic validation to ensure the birthdate is valid
- Responsive design to ensure compatibility with different devices
- Simple and clean user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- [Luxon](https://moment.github.io/luxon/)
- [Flatpickr](https://flatpickr.js.org/)

## Usage

1. Open the live demo link.
2. Enter your birthdate using the datepicker.
3. Click the "Calculate Age" button to see your exact age in years, months, and days.
